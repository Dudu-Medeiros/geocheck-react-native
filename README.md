# GeoCheck

Aplicativo mobile desenvolvido em React Native no Expo Snack utilizando geolocalização (`expo-location`).

## Funcionalidades
- Captura da localização atual (latitude, longitude e endereço).
- Tratamento de permissão negada com aviso ao usuário.
- Cadastro de check-in com nome do local.
- Tela de histórico com listagem e exclusão de lugares salvos.
